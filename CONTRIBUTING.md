# Contributing

Thanks for your interest. Issues and pull requests are welcome.

Before you write code, read [AGENTS.md](AGENTS.md) for the build, the gate and the code style,
and [docs/Safety.md](docs/Safety.md) for anything that can energise a relay.

copyright holder (see [COMMERCIAL-LICENSE.md](COMMERCIAL-LICENSE.md)). Dual licensing only works
if every line can be offered under both, so a contribution comes with this grant:

> I license my contribution to Greg Underwood under the AGPL-3.0, and also grant him a perpetual,
> worldwide, non-exclusive, royalty-free, irrevocable license to use, modify, sublicense and
> distribute it under any other terms, including commercial ones. I wrote the contribution, or
> otherwise have the right to grant this.

You keep the copyright in your work and can use it however you like. To agree, add this line to
each commit message:

```
Signed-off-by: Your Name <you@example.com>
```

`git commit -s` adds it for you. A pull request whose commits lack it can't be merged.
