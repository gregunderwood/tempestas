# Contributing

Thanks for your interest. Issues and pull requests are welcome.

Before you write code, read [AGENTS.md](AGENTS.md) for the build, the gate and the code style,
and [docs/Safety.md](docs/Safety.md) for anything that can energise a relay.

each commit message:

```

```

`git commit -s` adds it for you. A pull request whose commits lack it can't be merged.
